Frequently Asked Questions (FAQ)

Q1: Which operating systems are supported?

A: Windows 10 and 11 (64-bit) only. There is no macOS or Linux build you can buy today. The geometry kernel is compiled for Windows, so porting is a real piece of work rather than a flag flip.

To be straight about where that stands: builds for Linux and macOS (Apple Silicon) now exist and are being given to testers, but they are not on sale and have no release date. Nobody has confirmed them working inside Blender yet, and macOS notarisation needs a paid Apple Developer membership that is not funded — that, rather than the code, is the main thing in the way. Please buy only if you are on Windows. If you would like to test a build rather than buy one, get in touch.

Q2: Which Blender versions are compatible?

A: Blender 4.2 LTS through 5.1. Tested on 4.2, 4.3, 4.4 and 5.1.

Q3: Which file formats can it read and write?

A: STEP import and export, and SVG import for 2D profiles. STEP is the format that matters for moving real solids to and from SolidWorks, Fusion 360, Rhino or FreeCAD, and on to CNC or 3D printing. IGES is not supported. You can also bake any result to a normal Blender mesh and use Blender's own exporters from there.

Two things to know about STEP export specifically: 1 Blender unit is written as 1 mm and there is no export scale option, so build at millimetre scale; and the file carries geometry only — no part names, no colours, no assembly structure. The surfaces themselves are exact, not triangulated. STEP import does have a scale option.

Q4: Do I need separate CAD software or licenses installed?

A: No. The CAD kernel (OpenCASCADE) and everything it needs are bundled with the add-on. No third-party CAD licenses, and no separate runtime to install.

Q5: What does "Beta" actually mean here?

A: It works, and it is being used for real modeling — but it is still under active development. Expect rough edges, expect behaviour to change between updates, and please save your work. Bug reports genuinely shape what gets fixed next. The launch price reflects this stage.

Q6: Are future updates included with my purchase?

A: Yes. All updates in the 8.x series are included free of charge.

Q7: Is the source code available?

A: Yes. Blender add-ons are GPL, and this one is no exception — it ships under the GNU GPL v2 or later, and the source, including the Rust and C++ geometry kernel, is published openly. You are free to read it, learn from it and modify it.

Q8: How do I report a bug or request a feature?

A: Message me through Superhive, or open an issue on the project's GitHub tracker. Reports go straight to the developer — there is no support queue in between.

Q9: Is there a manual? Is it available in my language?

A: Yes, and you can read all of it before buying: hinatahugu29.github.io/Blender_Seamless_CAD

The full documentation is available in English and Japanese. A Quick Start is also available in Russian and Simplified Chinese.

To be straight with you about those last two: they were translated by AI and have not been reviewed by a native speaker, and each page says so at the top. If a translation and the English version disagree, the English version is the correct one. If you would like to help review or extend a translation, please get in touch.

The add-on's interface itself is in English in all cases.

Q10: Will it change my keymap? I use the Industry Compatible one.

A: It registers no keymap entries at all, so nothing you already use in Blender is rebound or overridden.

The part worth knowing is that the add-on's interactive modes — sketching, selection, transform — run as modal operators, and while one is running it handles keys itself. Viewport navigation is passed through, so middle mouse, the wheel and the numpad views keep working without leaving the mode. As of 8.1.5.8 the Industry Compatible keymap is passed through too, meaning Alt with a mouse button orbits, pans and zooms from inside a mode.

One overlap remains by design: in Selection Mode, Alt + left drag is also how you move a gizmo axis. It resolves by what is under the cursor — on a gizmo axis or a control point you grab it, anywhere else you orbit.

If you find a navigation key that a mode swallows, please report it. That is a bug, not intended behaviour, and the 8.1.5.8 fixes came from exactly such a report.
