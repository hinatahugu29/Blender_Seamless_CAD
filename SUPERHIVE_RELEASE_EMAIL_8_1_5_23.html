Seamless CAD

Version 8.1.5.23 is out

Bake a CAD part to a clean quad mesh with UVs and seams — ready to keep modelling in Blender.

Baking a CAD part to a mesh has always given you triangles: fine for rendering, awkward the moment you want to keep modelling it in Blender. This release adds a second kind of bake.

Quad Bake (beta)

In the Quality Bake panel, set Topology to Quad. The bake is then built from the part's own faces and edges rather than from a triangle soup: walls of cylinders and cones become clean rows of quads, curved four-sided faces get a grid, flat plates with holes get rings around each hole, and the leftover triangles are paired into quads.

The edges of the mesh follow the CAD edges exactly, so neighbouring faces meet with no gaps or slivers. Each CAD face gets its own UV island, the CAD edges are marked as seams, and the sharp ones are marked sharp.

Quad Density picks how fine it is (Low / Mid / High, or type your own tolerance). Subdiv creases the sharp edges and adds a Subdivision Surface modifier, so the result is ready to smooth. Spheres get proper cube-style caps at their poles instead of a fan of thin triangles, so they do not pinch when subdivided.

It is marked beta for a reason. Most parts come out almost entirely quads, but a few triangles are left where forcing a quad would mean a badly skewed one; the bake prefers a clean shape to a perfect count. If a part bakes badly, Copy Quad Bake Report puts a description of every face on the clipboard — pasting that into a message is the most useful report you can send.

One fix

Loft from a flat profile no longer leaves a hair-thin sliver. A loft that started from a zero-height surface, polygon or slot profile used to fuse a 0.0001-thick slab onto the part. It now gets one clean cap.
Updating
Download the build for your platform from your Superhive library and install it through Blender's Install from Disk, the same way as before.

Quit every Blender window first. This release changes the geometry program as well as the add-on, and on Linux and macOS that program cannot be replaced while it is running. The add-on will tell you in the console if it ends up talking to the old one, but starting clean avoids it entirely.
Two things to be straight about

macOS remains the least proven platform. The build comes from the same automated pipeline as the others and is checked to compile, bundle, start, answer and package completely — but no individual feature has been confirmed inside Blender on a Mac by the developer. If you are on a Mac, your report is the only way that changes.

The Linux undo abort in the test suite is still open. The cause has been narrowed down and a fix exists, but it changes when the add-on syncs after an undo and is not safe enough to ship yet. As before, it has not been reported from normal use. The suite is now 94 checks and passes on Windows.
