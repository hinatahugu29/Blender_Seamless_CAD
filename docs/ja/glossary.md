# 用語集

> 2026-08-10 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/glossary/) を参照してください。

**アドオンの UI は英語で、日本語化の予定はありません。**このページは、画面に出て
いる英語のラベルと、日本語で読んだときの意味を対応させるためのものです。
このマニュアルの他のページでもボタン名は英語のまま書いています。

Blender での意味と CAD での意味がずれる語には、そのずれも書いています。混乱の元は
だいたいそこです。

## 基本概念

| 画面の表記 | 訳・読み | 意味 |
|---|---|---|
| B-Rep | 境界表現 | カーネルが立体を表す方式。三角形ではなく、数式で定義された厳密な曲面・稜線・頂点で表します。円柱はどこまで拡大しても円柱です。STEP 書き出しはこれをそのまま書きます。**Bake to Mesh** はこれを捨てます |
| Kernel | カーネル | ジオメトリエンジン本体（OpenCASCADE / OCCT）。Blender とは**別プロセス**で動きます。ビューポートに見えているのは、それが計算した結果の絵です |
| Proxy | プロキシ | Feature Tree の項目を代表する軽量な Blender オブジェクト。位置・回転・スケールを持ち、<kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> で動かしているのはこれです。ジオメトリそのものではありません |
| Non-destructive | 非破壊 | 作ったあとも編集できるということ。20手前に作った Box は今も Box で、幅を打ち直せます。編集した瞬間に Box でなくなる Blender のメッシュモデリングとは逆です |
| Tessellation | テセレーション / 三角形分割 | 厳密な曲面を描画用の三角形に変換すること。**Linear** と **Curvature** で制御します。効くのは表示とベイクだけで、STEP 書き出しには影響しません |

## ツリーまわり

| 画面の表記 | 訳・読み | 意味 |
|---|---|---|
| Feature Tree | フィーチャーツリー | モデルを作る操作の順序付きリスト。上から下へ評価されます。**これがモデル本体**で、ビューポートはその結果です |
| Entry / Feature / Primitive | 項目 / フィーチャー / プリミティブ | Feature Tree の1行。UI にはこの3つの語が出てきますが、指すものは同じです。「Primitive」は内部名で、Fillet のような形状でないものにもツールチップ上そう出ることがあります |
| Operation | 合成方法 | その項目が上の結果とどう合わさるか。`Base` / `Add (Fuse)` / `Subtract (Cut)` / `Intersect (Common)` |
| Base | ベース | それより上を破棄して起点にする |
| Add (Fuse) | 結合 | 和。既定値 |
| Subtract (Cut) | 切り取り | 差 |
| Intersect (Common) | 共通部分 | 積 |
| Rollback point | ロールバックポイント | ピン。評価をその行で止め、それ以降を無視します |
| Part | パート | 独立した Feature Tree 1本、Blender のコレクション1つ。**評価されるのはアクティブな Part だけ**です |
| Group | グループ | `Group (` と `Group )` の対。その間の項目は1つずつではなく、まとまりとして残りと合成されます |
| Target | ターゲット | その項目が働きかける相手。パターンやスイープは**別の項目**を UUID で指し、モディファイア系は Selection Mode で選んだ**個別の面・稜線**を指します |
| Face / edge identity | 面・稜線の同一性 | カーネル内部での特定の面・稜線への参照。Fillet は座標ではなくこの同一性を覚えるので、ツリーの上のほうで寸法を変えても付いたままになります。**Cleanup (Unify)** がこれを壊します |

## 操作

| 画面の表記 | 訳・読み | 意味 |
|---|---|---|
| Fillet | フィレット | 稜線を丸める。**3D（Modify & Pattern）と 2D（スケッチの角）に同名で2つあります。**別の操作です |
| Chamfer | 面取り | 稜線を平らに削る。こちらも 3D と 2D に同名で2つあります |
| Draft | 抜き勾配 | 面に角度を付けて傾ける。成形品で必要になるもの。**Neutral Plane**（動かない基準面）と **Faces to Taper**（傾く面）の2つの選択が要ります |
| Neutral Plane | 中立面 / 基準面 | Draft で動かさない基準の面 |
| Faces to Taper | 傾ける面 | Draft で勾配を付ける面 |
| Shell | シェル / 中空化 | 肉厚を残して中を抜く。**Faces to Remove** に選んだ面が開口部になります |
| Faces to Remove | 取り除く面 | Shell で開口部になる面 |
| Inset | インセット | 面をその輪郭の内側に取る |
| Offset | オフセット | 面を法線方向に動かす |
| Loft | ロフト | 2つ以上のプロファイルの間をつなぐ。**Face Loft** は既存ソリッドの選択面どうしで同じことをします |
| Sweep | スイープ | プロファイルをパスに沿って走らせる |
| Revolve | 回転体 | プロファイルを軸まわりに回す |
| Cleanup (Unify) | 統合 | 同一平面上の面をまとめてトポロジーを単純化する。面の同一性を壊すため**意図的に手動**です。書き出し直前の最終工程で、履歴の途中で使うものではありません |
| Instance / Link | インスタンス / リンク | 実体を複製せず、元のボディを共有する複製 |
| Independent | 独立 | パターンのトグル。パターン自身のトランスフォームを、元の形状のトランスフォームに重ねるか、独立させるかを決めます |
| Bake | ベイク | CAD の結果を通常の Blender メッシュに変換する。**スナップショット**であり、以後は連動しません |

## スケッチ

| 画面の表記 | 訳・読み | 意味 |
|---|---|---|
| Constraint | 拘束 | ソルバが満たすべき規則（距離、平行、接線など）。**ざっくり描いてから拘束で固める**のがこのスケッチャの使い方です |
| GCS | 幾何拘束ソルバ | すべての拘束を同時に満たす位置を求める部分 |
| Construction geometry | 構築線 | 参照用に残す線。拘束の相手やミラーの軸に使い、結果の形状には含まれません |
| Over-constrained | 過拘束 | 自由度に対して拘束が多すぎる状態。スケッチが思ったように動かなくなります。原因を見つける場所は拘束の一覧です |
| Inference | インファレンス | 既存の点と座標が揃ったときに出る、一時的な点線のガイド |
| Island | アイランド | スケッチの中の1つの閉領域。閉じたループが3つあるスケッチは、Feature Tree の項目を3つ作ります |
| Apply / Cancel | 確定 / 破棄 | スケッチモードを終える2つのボタン。**キーボードでは終われません** |

## 書き出し

| 画面の表記 | 訳・読み | 意味 |
|---|---|---|
| STEP | ステップ | CAD 間でやりとりする中立フォーマット。書き出しは AP214 IS で、**ジオメトリのみ**。名前も色もアセンブリ構造も入りません |
| AP214 | — | 書き出しに使っている STEP のアプリケーションプロトコル。相手先から聞かれることがあります |
| Linear / Curvature | 直線偏差 / 角度偏差 | 表示用メッシュの細かさ。小さいほど細かく、遅くなります |
