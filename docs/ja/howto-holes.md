# ハウツー: 穴とポケットを開ける

> 2026-08-10 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/howto-holes/) を参照してください。
>
> **アドオンの UI は英語です。** このページではボタン名を英語のまま書きます。

切り取りは専用のツールではありません。形状を追加し、その **Operation** を
`Subtract (Cut)` にすると、それより上にあるものから自分を差し引きます。

切り取る側の形状も編集可能な項目としてツリーに残るので、後から選んで数値を打ち
直せば穴の径が変わります。

## 丸穴

1. **Create > Cyl** で円柱を追加します
2. 材料を貫通する位置に置きます。ビューポートで <kbd>G</kbd>、または
   **Active Property Editor** に座標を打ち込みます
3. その円柱をアクティブにしたまま、**Operation** を `Subtract (Cut)` にします

**切り取る側は材料より長くしてください。**円柱の端が面とぴったり同一平面になる
状態は「同一面（coincident surface）」の場合にあたり、どのカーネルでもブーリアンが
最も不安定になるところです。両側に少し突き出させてください。結果の形は変わりま
せんが、安定性が変わります。

## 任意形状のポケット

円でないものを掘る場合:

1. 掘りたい面を選びます
2. **Create > on Face**
3. 輪郭を描いて拘束します — [ハウツー: スケッチから立体を作る](howto-sketch-to-solid.md)
   を参照
4. **Apply**
5. **Sketch Surface** の項目を選び、**Extrude Height** に**負の値**を入れます。
   これで外側ではなく材料の内側へ押し出されます
6. **Operation** を `Subtract (Cut)` にします

ポケットではなく貫通穴にしたい場合は、材料の厚みより大きい負の値を使います。

## 同じ穴をたくさん開ける

同じ穴を10回作らないでください。1つ開けてからパターンにします。

1. 上の手順で最初の穴を開けます
2. **Modify & Pattern > Array**（直線配列）または **Circ**（円形配列）
3. Property Editor でパターンの **Target** に切り取り用の形状を指定します。
   リストから選ぶ **Pick Target** か、**Pick Target in Viewport** を使います
4. 個数と間隔を設定します
5. パターンの項目自身の **Operation** も `Subtract (Cut)` にします。これで複製側も
   切り取ります

後から元の穴の径を変えると、複製すべてに反映されます。パターンはジオメトリの
コピーではなく、項目そのものを参照しているためです。

> **Independent** のトグルは、パターン自身のトランスフォームを元の形状の
> トランスフォームに重ねるか、置き換えるかを決めます。パターンが思わぬ位置に
> 出るときは、まずここを見てください。

## 穴の縁を丸める

1. **Selection Mode > ENTER Selection Mode**
2. 選択タイプを稜線にします
3. 穴の稜線を1本クリックし、少し回った位置の稜線を <kbd>Ctrl</kbd>+クリックします。
   2点間の最短経路が一度に選ばれ、ホバー中に経路がプレビュー表示されます
4. **Modify & Pattern > Fillet** を押し、半径を設定します

穴の縁なら、8回のクリックではなく2回で済むのが普通です。

**可変フィレット。**Fillet に対象が設定されると、Property Editor が稜線を1本ずつ
列挙し、**Use Default** / **Custom** の切り替えを表示します。Custom にした稜線
だけが独自の半径を持ちます。

## 順序が結果を変える

ブーリアンの**前**に置いたフィレットは、その時点の形状を丸めます。**後**に置いた
同じフィレットは、切り取った結果を丸めます。これは別のモデルであり、しかも
ツリーは並べ替えられません。[Feature Tree と Part](feature-tree.md) を参照して
ください。

実務上の原則は、**先に切り、後から丸める**ことです。まだ切り取っていない穴を
丸めると、丸まるのは切り取る側の円柱であって、たいてい意図と違います。

## 切り取りがうまくいかないとき

**何も削れていない。**
**Operation** が本当に `Subtract (Cut)` になっているか、切り取る側が材料と
重なっているかを確認してください。表面に触れているだけでは何も削れません。

**ドラッグ中はおかしいが、離すと正しい。**
**Live Boolean Preview** です。気になる場合は **Quality & Export** で切ってくだ
さい。確定後の結果は常に正確です。
[品質とパフォーマンス](quality.md) を参照してください。

**切れていたのに、前の工程を編集したら壊れた。**
下流のフィレットやオフセットが、参照していた面を見失っています。
[困ったとき](troubleshooting.md) を参照してください。
