# macOS / Linux のテストビルド

> 2026-08-09 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/testing-builds/) を参照してください。

Seamless CAD が販売しているのは Windows 版です。macOS 版と Linux 版のビルドが
できたので、テスターの方にお渡ししています。

**製品ではありません。**販売しておらず、リリース時期も未定で、このページは
リリースを約束するものでもありません。

まったく動かない可能性のあるソフトを動かしてみて、動かなかったときに何が
起きたかを丁寧に書き留めてくださる方であれば、どうぞお試しください。

## あるもの

| | |
|---|---|
| Linux | x86-64 |
| macOS | Apple Silicon (arm64) |
| macOS Intel | ビルドなし |

アドオン本体は Windows 版とファイル単位で同一のコードです。プラットフォームごとに
作り直しているのは、実際の CAD 計算を行う**別プロセスの形状カーネル**だけです。

## 動作要件

**共通:** Blender 4.2 以降。開発と動作確認は 5.1 で行っています。

**Linux:** glibc 2.34 以降と、GLIBCXX_3.4.30 を提供する C++ ランタイム。
実質的には Ubuntu 22.04、Debian 12、RHEL 9 以降に相当します。X11・fontconfig・
freetype はシステムのものを使います（Blender 自身も必要とするので、Blender が
動いていれば入っています）。

**macOS:** Apple Silicon、macOS 11 以降。**Intel Mac では動きません。**

## 確認できていること / できていないこと

ここは正確に書きます。

**ビルドのたびに自動で確認していること:**

- カーネルが OpenCASCADE 8.0.1 に対してソースからビルドできること
- 必要な共有ライブラリがすべて同梱され、**ビルドマシンの環境に頼らずに**
  解決できること
- カーネルが起動し、待ち受けポートに応答すること

**一度も確認していないこと:**

- **Blender の中で動かすこと。誰も、一度も、やっていません。**
  上の検査はすべて Blender の外で行われています
- 形状の作成・編集
- ビューポートの描画。macOS の Metal バックエンドが動くかどうかも含めて
- STEP / SVG の読み書き
- セッションを通した安定性

つまり、テスターの方が最初に行う操作 — **Start Seamless CAD** を押して
直方体が出るかを見る — が、そのまま新しい情報になります。カーネルとの通信と
描画経路を同時に通るためです。

**失って困るデータには使わないでください。**こまめに保存し、大事なものは
別ファイルに分けてください。

## インストール

Windows 版と同じです。

1. Blender で `Edit > Preferences > Add-ons > Install...` を開く
2. お送りした `.zip` を選ぶ
3. アドオンを有効化する
4. 3D ビューポートで <kbd>N</kbd> を押す。**Seamless** タブが出ます

あとは [クイックスタート](quickstart.md) に従ってください。

### macOS: セッションを開始しても何も起きない場合

カーネルには署名がありますが **ad-hoc 署名**です。Apple の公証を通していません
（有料の Apple Developer 登録が必要で、まだ費用を確保できていません）。
macOS が実行を拒む可能性があります。

そのまま動く見込みもあります。ZIP を展開するのは Blender 自身で、その方法で
展開されたファイルは通常、検査の引き金になる quarantine 属性を引き継がないためです。
**ただし実機で確認できていません。**これも確かめていただきたいことの一つです。

アドオンは読み込まれるのに形状がまったく出ない場合は、属性を手動で外してください。

```bash
xattr -dr com.apple.quarantine ~/Library/Application\ Support/Blender/*/scripts/addons/CAD_8_1_5_1
```

そのうえで Blender を再起動します。**このコマンドが必要だったかどうかを、
ぜひ報告してください。**こちらからは判断できない事柄の一つです。

## 報告のしかた

件数よりも、丁寧な1件のほうがはるかに役に立ちます。特に助かるのは:

- **何をしたか。**他の人が再現できる程度に、順を追って。
  「ブーリアンが壊れている」より「Box を追加し、幅を30にし、Cyl を追加して
  引き算に設定した」のほうが桁違いに有用です
- **何が起きたか。**そして何が起きると思っていたか
- **新しいファイルでも再現するか**
- **環境:** OS とそのバージョン、CPU（Apple Silicon か / どのディストリか）、
  Blender のバージョン、ZIP のファイル名にあるアドオンのバージョン

添えていただけると対応が大きく変わるものが2つあります。

**カーネルのログ。**形状カーネルが一時ディレクトリに書き出しています。

- Linux: `/tmp/seamless_cad_server_debug.log`
- macOS: `$TMPDIR/seamless_cad_server_debug.log`

**Blender のコンソール出力。**ターミナルから Blender を起動すると、アドオンの
メッセージがそこに出ます。macOS では
`/Applications/Blender.app/Contents/MacOS/Blender` です。

Blender ごと落ちた場合は、落ちた瞬間に何をしていたかを書いてください。
「わからないが、何かをドラッグしていた」でも十分に絞り込みの役に立ちます。

**「そもそも起動しない」という報告も、モデリングの報告と同じだけ価値があります。**
現時点では「起動して直方体が描けた」ということ自体が、聞く価値のある結果です。
