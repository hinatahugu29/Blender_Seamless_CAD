# 読み込みと書き出し

## STEP の読み込み

`Quality & Export > Import > STEP`。`.stp` と `.step` を受け付けます。

読み込みダイアログのオプションは **Scale** の1つだけで、取り込むときに一律で
掛ける倍率です。ダイアログ自身にもよくある例が書かれています。`0.001` はミリメートル
からメートルへの変換、`1.0` はそのままの寸法です。

ファイル内の各ソリッドが、`STEP Part …` という名前の Feature Tree 項目になります。
空のパーツに最初に読み込んだものが `Base` になり、以降は `Add (Fuse)` になります。
読み込んだパーツは**普通のツリー項目**なので、動かすことも、Operation を変えることも、
ブーリアンで切ることもできます。

指定した Scale は項目とともに保存されるので、再読み込みしても寸法が食い違いません。

## SVG の読み込み

`Quality & Export > Import > SVG`。`.svg` を受け付け、同じく **Scale** の倍率を
取ります。

2Dプロファイルとして取り込まれるので、これを掃引・ロフト・回転させてソリッドに
できます。

> SVG の読み込みは、同梱の `svgpathtools` と `svgwrite` に依存しています。
> パッケージングスクリプトは、リリースをビルドする前にこれらが実際に import
> できるかを検査します。**過去にディレクトリコピーで脱落し、SVG インポートが
> 10バージョン以上にわたって無言で壊れていた**ためです。

## STEP の書き出し

`Quality & Export > Export > STEP`。`.stp` を書き出します。

出力されるのは **AP214 IS** の、本物の B-Rep の STEP ファイルです。三角形近似では
なく厳密な曲面が書き出されるので、表示品質の設定は一切影響しません。

### スケール

**既定では 1 Blender 単位が 1 mm として書き出されます。**10 単位の直方体は、
FreeCAD や Fusion、SolidWorks で 10 mm の直方体として開きます。

別の基準で作っている場合は、書き出しダイアログの *Scale (1 unit = N mm)* を
設定してください。1 単位がメートルなら 1000、センチメートルなら 10 です。
読み込み側の Scale と同じ量なので、10 で取り込んだファイルは 10 で書き出せば
そのまま戻ります。1.0 のままなら、これまでの版と同じ挙動です。

### パーツ名とアセンブリ

**Part のコレクション名が製品名として書き込まれます。**FreeCAD / Fusion /
SolidWorks で開いたとき、無名のボディではなく、付けた名前のまま届きます。

**All Parts as Assembly** を入れると、シーン内のすべての CAD Part を1つの
ファイルにまとめ、アセンブリとして関係づけて書き出します。

```
Assembly
  ├─ Bracket
  └─ Housing
```

最上位の名前は **Assembly Name** で決めます。まだ形状の無い Part は、空の
項目として書かずに読み飛ばします。既定はオフで、その場合は作業中の Part
だけを書き出します。

### ファイルに入らないもの

**色は入りません。**理由は書き出し側ではなくその手前にあります。このアドオンには
Part にも面にも色を設定する場所がないので、**ファイルに書く元の色が存在しません。**
形状・名前・構造はいずれも入ります。

> **「FreeCAD で開けた」は弱い検証で、信用しないほうがいいです。**FreeCAD は
> 他の CAD が拒否するファイルも開きます。特定のソフトに渡すことが決まっているなら、
> そのソフトで検証してください。

## STL の書き出し

`Quality & Export > Export > STL`。`.stl` を書き出します。既定はバイナリです。

カーネルからファイルへ直接書き出します。先に Bake する必要は**ありません**し、
しないほうが結果は良くなります。テセレーションにこのパネルの品質設定を使うため、
**Use High Quality Bake** を入れておくと、Blender メッシュを経由するより
細かい STL が出ます。

*Scale (1 unit = N mm)* の意味は STEP と同じです。**ASCII** を入れるとテキスト形式に
なります。サイズがはるかに大きくなるので、中身を自分で読みたいとき以外は不要です。

Part が空だったり、テセレーションで三角形が1枚も出なかった場合は、
**ファイルを書かずに**エラーになります。開けたのに中身が空だった、という結果より、
書かないほうがましだからです。

## IGES の書き出し

`Quality & Export > Export > IGES`。`.igs` を書き出します。

**形状のみで、名前もアセンブリ構造も入りません。**IGES は名前の扱いが読み手に
よって食い違いすぎて当てにできないためです。**STEP を優先してください。**
IGES があるのは、受け取る側のソフトが他を読めない場合のためです。

*Scale* は上と同じです。**Solid (BRep)** を切ると、ソリッドではなくトリム面の
集まりとして書き出します。古い読み手はそちらのほうが扱えることがあります。

## Bake to Mesh（メッシュ化）

`Quality & Export > Bake to Mesh`。もう一つの出口で、こちらは Blender の中に
とどまります。

CAD の結果が `SeamlessBake` という名前の通常の Blender メッシュオブジェクトに
変換され、`Seamless_CAD` の下の **Result** コレクションに置かれます。作成時に
選択され、アクティブになります。

レンダリング、スカルプト、Blender 標準のエクスポーター経由の書き出しなど、本物の
Blender ジオメトリが必要なすべての用途に使います。

レンダリング用なら、先に **Use High Quality Bake** を有効にしてください。有効な
場合、メッシュ生成の前にカーネルがベイク設定で再テセレーションします。
[品質とパフォーマンス](quality.md) を参照してください。

**ベイクはスナップショットです。**Feature Tree とリンクしたままにはなりません。
あとからモデルを変更したら、もう一度ベイクする必要があります。既存の
`SeamlessBake` オブジェクトは更新されません。

## どちらを使うか

| やりたいこと | 使うもの |
|---|---|
| レンダリング、スカルプト、Blender のツールを使う | **Bake to Mesh** |
| 他の CAD ソフトでパーツを開く | **Export STEP** |
| 製造用に厳密な形状を渡す | **Export STEP** |
| 複数パーツを1つのアセンブリとして渡す | **Export STEP** の All Parts as Assembly |
| 3Dプリント、スライサーに渡す | **Export STL** |
| 受け取る側が IGES しか読めない | **Export IGES** |
| Blender の glTF / FBX / OBJ で書き出す | まず **Bake to Mesh** |

出力先がプリンタなら、Bake to Mesh ではなく **Export STL** を使ってください。
どちらも三角形になりますが、直接の書き出しは Blender のメッシュを往復せず、
カーネルのテセレーションをそのまま保ちます。
