# 読み込みと書き出し

## STEP の読み込み

`Quality & Export > Import STEP`。`.stp` と `.step` を受け付けます。

読み込みダイアログのオプションは **Scale** の1つだけで、取り込むときに一律で
掛ける倍率です。ダイアログ自身にもよくある例が書かれています。`0.001` はミリメートル
からメートルへの変換、`1.0` はそのままの寸法です。

ファイル内の各ソリッドが、`STEP Part …` という名前の Feature Tree 項目になります。
空のパーツに最初に読み込んだものが `Base` になり、以降は `Add (Fuse)` になります。
読み込んだパーツは**普通のツリー項目**なので、動かすことも、Operation を変えることも、
ブーリアンで切ることもできます。

指定した Scale は項目とともに保存されるので、再読み込みしても寸法が食い違いません。

## SVG の読み込み

`Quality & Export > Import SVG`。`.svg` を受け付け、同じく **Scale** の倍率を
取ります。

2Dプロファイルとして取り込まれるので、これを掃引・ロフト・回転させてソリッドに
できます。

> SVG の読み込みは、同梱の `svgpathtools` と `svgwrite` に依存しています。
> パッケージングスクリプトは、リリースをビルドする前にこれらが実際に import
> できるかを検査します。**過去にディレクトリコピーで脱落し、SVG インポートが
> 10バージョン以上にわたって無言で壊れていた**ためです。

## STEP の書き出し

`Quality & Export > Export STEP`。`.stp` を書き出します。

出力されるのは **AP214 IS** の、本物の B-Rep の STEP ファイルです。三角形近似では
なく厳密な曲面が書き出されるので、表示品質の設定は一切影響しません。

### スケール

**1 Blender 単位が 1 mm として書き出されます。**10 単位の直方体は、FreeCAD や
Fusion、SolidWorks で 10 mm の直方体として開きます。**書き出し側にスケールの
オプションはありません**ので、最初からこれを前提に寸法を決めてください。

### ファイルに入らないもの

誰かにファイルを渡す前に知っておいてください。

- **パーツ名は入りません。**エンティティは無名です
- **色は入りません**
- **アセンブリ構造は入りません。**形状がフラットに入っているだけです

形状は厳密で正確です。ただ、その周辺の情報が書き出されないというだけです。
受け取る側が「名前と色のついた構造化アセンブリ」を必要としているなら、現時点の
書き出しではその要求を満たせません。

> **「FreeCAD で開けた」は弱い検証で、信用しないほうがいいです。**FreeCAD は
> 他の CAD が拒否するファイルも開きます。特定のソフトに渡すことが決まっているなら、
> そのソフトで検証してください。

## Bake to Mesh（メッシュ化）

`Quality & Export > Bake to Mesh`。もう一つの出口で、こちらは Blender の中に
とどまります。

CAD の結果が `SeamlessBake` という名前の通常の Blender メッシュオブジェクトに
変換され、`Seamless_CAD` の下の **Result** コレクションに置かれます。作成時に
選択され、アクティブになります。

レンダリング、スカルプト、Blender 標準のエクスポーター経由の書き出しなど、本物の
Blender ジオメトリが必要なすべての用途に使います。

レンダリング用なら、先に **Use High Quality Bake** を有効にしてください。有効な
場合、メッシュ生成の前にカーネルがベイク設定で再テセレーションします。
[品質とパフォーマンス](quality.md) を参照してください。

**ベイクはスナップショットです。**Feature Tree とリンクしたままにはなりません。
あとからモデルを変更したら、もう一度ベイクする必要があります。既存の
`SeamlessBake` オブジェクトは更新されません。

## どちらを使うか

| やりたいこと | 使うもの |
|---|---|
| レンダリング、スカルプト、Blender のツールを使う | **Bake to Mesh** |
| 他の CAD ソフトでパーツを開く | **Export STEP** |
| 製造用に厳密な形状を渡す | **Export STEP** |
| Blender の glTF / FBX / OBJ で書き出す | まず **Bake to Mesh** |
