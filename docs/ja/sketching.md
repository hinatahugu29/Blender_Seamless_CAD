# スケッチ

スケッチモードでは、拘束のついた2Dプロファイルを描き、それを Feature Tree の項目に
します。ソルバーを備えたスケッチャーなので、**まず大まかに描き、あとから拘束で
形を確定させる**という使い方をします。

## 入り方と抜け方

**Create** パネルから：

- **Start Sketch** — 平面上でスケッチする
- **on Face** — 先に既存の面を選び、その上でスケッチする

スケッチモード中は、通常のパネルが **Seamless CAD - Sketch Mode** に置き換わります。
一番下の2つのボタンで終了します。

- **Apply** — スケッチを Feature Tree の項目にする
- **Cancel** — 破棄する

スケッチから作られた項目は、元のスケッチへのリンクを保持しています。後からその項目を
選ぶと Property Editor に **Edit Sketch** が現れ、作り直すことなく元のスケッチを
開き直せます。

> **Edit Sketch** が無効で「Hidden by rollback point」と出ている場合、その項目は
> 有効なロールバックピンより下にあります。先にピンを外してください。

## グリッド

| コントロール | 効果 |
|---|---|
| **Show Grid** | スケッチグリッドを表示 |
| **Grid Snap** | 描画をグリッドにスナップ |
| **Vertex Snap** | 近くの既存の点を使い回す（新しい点を作らない） |

Show Grid と Grid Snap は独立しています。表示していないグリッドにスナップすることも、
スナップしないグリッドを表示することもできます。

**Vertex Snap** は既定で ON で、新しく描いたものを既存の形状に繋げる役割を持ちます。
近くにあっても別々の点のままにしたいときは OFF にするか、<kbd>Ctrl</kbd> を
押しながらクリックしてそのクリックだけ無効にします。OFF でも頂点の選択はできます。

## ペンツール

同時に有効なのは1つだけです。

| ツール | 描くもの |
|---|---|
| **Select** | 描かない。既存の図形を選択します |
| **Point** | 点 |
| **Line** | 線分 |
| **Arc** | 円弧 |
| **Circle** | 円 |
| **Semi-circle** | 半円 |
| **Rectangle** | 対角の2点で決める矩形 |
| **Center Rect** | 中心から広げる矩形 |
| **Trim / Extend** | クリックで切り詰め／延長 |
| **Slot** | 長穴 |

## Selection Info（選択情報）

いま何が選ばれているか（点1つ、点2つ、線1本、線2本）を、内部 ID つきで表示します。
**ID が重要なのは、拘束が対象の ID で一覧表示されるためです。**

点を1つ選んでいるときは **X** / **Y** が編集可能になります。線を選んでいるときは、
始点と終点の点 ID が表示されます。

選択対象にすでに **Distance** 拘束がついている場合、その値をここで直接編集できます。
円弧の場合、同じ欄が **Length** ではなく **Radius** と表示されます。円弧の拘束は
中心と中間点の間に張られているためです。

## 拘束

| 拘束 | 意味 |
|---|---|
| **Fixed** | 選択対象をその場に固定 |
| **Distance** | 距離を指定。指定可能で、かつまだ付いていないときだけ表示されます |
| **Align X** | 水平にする |
| **Align Y** | 垂直にする |
| **Parallel** | 2本の線を平行に |
| **Perpendicular** | 2本の線を直角に |
| **Coincident (Point Merge)** | 2つの点を1つに統合 |
| **Midpoint** | 点を中点に拘束 |
| **Tangent** | 接する |

**Distance が出たり消えたりするのは仕様です。**現在の選択が距離拘束を取れる状態で、
**かつまだ付いていない**ときにだけ表示されます。見当たらないなら、その拘束はすでに
存在しています。Selection Info を見てください。そこで値を編集できます。

### 拘束の一覧

**Constraints / Parameters** を押すと、スケッチ内のすべての拘束が一覧表示されます。
各行には拘束の種類と対象の ID、編集可能な値があればその値（Distance と Arc Radius に
はあり、それ以外は `-`）、そして削除用のゴミ箱アイコンが並びます。

**スケッチが思ったように動かないときに見る場所がここです。**原因はたいてい拘束の
過剰で、犯人を見つけて消せるのはこの一覧だけです。

## 図形と操作

| 操作 | ショートカット | 備考 |
|---|---|---|
| **Toggle Construction** | — | 図形を作図線に切り替えます。参照には使われますが、形状にはなりません |
| **Select All** | <kbd>Ctrl</kbd>+<kbd>A</kbd> | |
| **Chain Select** | <kbd>L</kbd> | つながった一連の図形を選択 |
| **Copy** | <kbd>Ctrl</kbd>+<kbd>C</kbd> | |
| **Paste** | <kbd>Ctrl</kbd>+<kbd>V</kbd> | 何もコピーしていない間はグレーアウトします |
| **Trim** | — | 選択を切り詰め |
| **Extend** | — | 選択を延長 |
| **Offset Lines** | — | 隣の **Offset** の値だけオフセット |
| **Mirror X** / **Mirror Y** | — | 選択を鏡像化 |
| **Undo** | <kbd>Ctrl</kbd>+<kbd>Z</kbd> | スケッチモードは Blender とは別の独自の Undo を持ちます |

## Corner Tools（角の処理）

| ツール | 値 |
|---|---|
| **Fillet** | Fillet Radius |
| **Chamfer** | Chamfer Distance |

先に値を入れてからボタンを押します。これらはスケッチの角に対する操作で、
**Modify & Pattern** にある3Dの Fillet / Chamfer とは別物です。
