短い答えと、詳しく書いてあるページへのリンクです。

## 購入と対応環境

**対応 OS は?**
Windows 10 / 11 の 64bit です。製品として販売しているのはこれだけです。

Linux（x86-64）と macOS（Apple Silicon）のビルドは存在し、テスターに配布して
いますが、販売しておらず、リリース時期も未定です。Blender の中で動くことをまだ
誰も確認していません。また macOS の公証（notarization）には有料の Apple Developer
メンバーシップが必要で、その費用を確保できていません。コードではなくこれが最大の
障害です。購入は Windows の方に限ってください。
[macOS / Linux テストビルド](testing-builds.md) を参照してください。

**対応する Blender のバージョンは?**
4.2 LTS 以上。4.2 / 4.3 / 4.4 / 5.1 で検証しています。

**別途 CAD ソフトや CAD のライセンスが必要ですか?**
不要です。カーネル（OpenCASCADE）と必要なものはすべて同梱しています。ほかに
入れるものはありません。[インストール](install.md) を参照してください。

**アップデートは含まれますか?**
8.x 系のアップデートはすべて含まれます。

**ソースコードは公開されていますか?**
公開しています。Blender のアドオンは GPL であり、本アドオンも例外ではありません。
GNU GPL v2 以降で、Rust と C++ のジオメトリカーネルを含めてソースを公開しています。

**「ベータ」とは具体的にどういう状態ですか?**
動作しますし、実際のモデリングに使われていますが、開発の途上にあります。粗い部分は
残っていますし、アップデートで挙動が変わることもあります。こまめに保存してください。
[既知の制約](limitations.md) を参照してください。

## できること・できないこと

**Fusion や SolidWorks のようなパラメトリック CAD ですか?**
履歴ベースで非破壊です。すべての操作は後から戻って編集できる
[Feature Tree](feature-tree.md) として残ります。ただしそれらのパッケージほど
機能は揃っていません。正直な一覧は [既知の制約](limitations.md) にあります。

**CAD 形状に Blender のモディファイアやメッシュツールを使えますか?**
そのままでは使えません。形状は Blender のメッシュシステムではなくカーネルが計算して
います。先に **Bake to Mesh** すれば通常のメッシュになり、Blender の機能がすべて
使えます。[読み込みと書き出し](import-export.md) を参照してください。

**<kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> は使えますか?**
使えます。動かしているのは通常の Blender オブジェクト（プロキシ）で、ジオメトリが
リアルタイムに追従します。[仕組み](concepts.md) を参照してください。

**Blender の元に戻す（Undo）は効きますか?**
アドオンの操作については効きます。例外はスケッチモードで、独自のアンドゥ履歴を
持つため、スケッチ中の <kbd>Ctrl</kbd>+<kbd>Z</kbd> は Blender の操作ではなく
スケッチの手順を戻します。

**Feature Tree を並べ替えられますか?**
できません。順序は作成順で固定され、行の移動も、途中への挿入もできません。
代わりに何をするかは [Feature Tree と Part](feature-tree.md) にあります。

**アセンブリや合致（マージン/拘束）の機能はありますか?**
ありません。Part は複数持てて互いに独立していますが、Part 間の拘束はありません。

## ファイル

**読み書きできる形式は?**
STEP の入出力と、SVG の読み込みです。それ以外は **Bake to Mesh** してから Blender
標準のエクスポーターを通します。IGES には対応していません。

**STEP 書き出しのスケールは?**
1 Blender ユニットを 1 mm として書き、変更する設定はありません。ミリメートル基準で
作ってください。
[ハウツー: 他の CAD とファイルをやりとりする](howto-cad-exchange.md) を参照して
ください。

**書き出したファイルに名前や色が入らないのはなぜですか?**
STEP 書き出しはジオメトリのみを書きます。部品名も色もアセンブリ構造も入りません。
曲面そのものは厳密です。[既知の制約](limitations.md) を参照してください。

**書き出されるのは三角形分割された形状ですか?**
違います。厳密な B-Rep の曲面を書きます。表示品質の設定は影響しません。

## 使っていて詰まったとき

**何も計算されない。まず何を見ますか?**
`編集 > プリファレンス > アドオン` で Seamless CAD を展開し、
**CAD Engine: Running / Not running** を読んでください。実際のプロセスの状態を
反映しています。動いていない場合は、ポート 8080 を他のプログラムが使っていないかを
確認してください（[インストール](install.md)）。その次に
[困ったとき](troubleshooting.md) です。

**ドラッグ中はプレビューがおかしく、離すと正しいのはなぜ?**
**Fast Modifier Preview** と **Live Boolean Preview** が、正確さと引き換えに反応を
優先しているためです。確定後の結果は常に正確に計算されます。
[品質とパフォーマンス](quality.md) を参照してください。

**前の工程を変えたらフィレットが壊れました。**
フィレットは特定の面・稜線の同一性を参照しており、参照先の面が失われたためです。
原因はたいてい **Cleanup (Unify)** です。[仕組み](concepts.md) を参照してください。

**動作が重い。何が一番効きますか?**
ツリーの途中にロールバックのピンを刺すことです。それより下は評価されなくなります。
次にプレビューを切り、そのあと Linear と Curvature の値を上げます。
[品質とパフォーマンス](quality.md) を参照してください。

**スケッチを Apply したのに立体が出てきません。**
スケッチが作るのは面であって立体ではありません。**Extrude Height** を設定して
ください。既定値は `0.0` です。
[ハウツー: スケッチから立体を作る](howto-sketch-to-solid.md) を参照してください。

## ドキュメントとサポート

**マニュアルは何語で読めますか?**
英語と日本語が全ページ、ロシア語と簡体字中国語はクイックスタートのみです。後者2つは
AI による翻訳で、母語話者の校閲を受けていません（各ページ冒頭に明記しています）。
翻訳と英語版が食い違う場合は英語版が正しいものです。アドオンの UI はいずれの場合も
英語です。

**不具合の報告はどこへ?**
製品ページか、GitHub の issue トラッカーへお願いします。開発者に直接届きます。
どう書くと対処しやすいかは
[macOS / Linux テストビルド](testing-builds.md) の「報告」の節に書いてあり、
Windows でも同じです。
