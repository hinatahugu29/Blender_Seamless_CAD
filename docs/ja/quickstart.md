# クイックスタート

> 2026-08-09 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/quickstart/) を参照してください。
>
> **アドオンの UI は英語です。** このページではボタン名を英語のまま書き、必要に応じて
> 意味を補足します。画面に出ている文字とこのページの表記は一致します。

インストールから、STEP ファイルとして書き出すところまでを一通り扱います。
所要時間はおよそ10分です。

Seamless CAD はベータ版で、販売しているのは Windows 版です。このページの内容は
macOS / Linux の [テストビルド](testing-builds.md) にもそのまま当てはまります
（アドオン本体は同じものです）。

---

## 1. インストール

1. Blender で `Edit > Preferences > Add-ons > Install...` を開く
2. `CAD_<バージョン>_install.zip` を選ぶ
3. アドオンを有効化する
4. 3D ビューポートで <kbd>N</kbd> を押してサイドバーを開く。**Seamless** タブが出ます

Blender 4.2 以降が必要です。開発と動作確認は 5.1 で行っています。

## 2. セッションを開始する

**Seamless** タブを開きます。まだ何も無い状態では、ボタンが1つだけ表示されます。

- **Start Seamless CAD**

これを押すと、形状計算のカーネルが起動し、最初の CAD パーツが作られます。

> **内部で何が起きているか：** 形状は Blender のメッシュ機能ではなく、別プロセスの
> OpenCASCADE (OCCT) が計算し、その結果を Blender が描画しています。アドオンが
> 実行ファイルを同梱しているのも、最初の起動に少し時間がかかるのも、この構造の
> ためです。

## 3. ワークスペースの考え方

**Active CAD Workspace**（作業中の CAD パーツ）パネルで、どのパーツを編集して
いるかを切り替えます。

- ドロップダウンで、対象のパーツコレクションを選ぶ
- **Add New CAD Part** で、独立した別のパーツを追加する
- ゴミ箱アイコンで、現在のパーツを削除する

以降のパネルの操作は、すべて**選択中のパーツにだけ**効きます。下のパネルが
表示されない場合は、有効なパーツが選ばれていません。ドロップダウンから選ぶか、
新しく追加してください。

## 4. 最初の形状を作る

**Create** パネルを開いて **Box** を押します。

ビューポートに直方体が現れ、同時に **Feature Tree**（形状の履歴）パネルにも
項目が1つ増えます。この2つは同じものの別の見え方です。ビューポートは計算結果を、
Feature Tree はその結果を作った手順を表示しています。

Create パネルは行ごとに種類が分かれています。

| 行 | 内容 |
|---|---|
| ソリッド | Box, Cyl, Sph, Cone, Torus |
| 曲線・プロファイル | Curv, Plin, Arc, Surf, Slot, Poly, Gear, Helix, Rev |
| スイープ形状 | Sweep, Loft |
| グループ化 | Group ( , Group ) |
| スケッチ | Start Sketch, on Face |

## 5. 後から編集できる — ここが本題

**Feature Tree** の中の Box の項目をクリックします。下の **Active Property
Editor**（プロパティ編集）パネルに、そのパラメータが出ます。幅を変えてみて
ください。

形状が作り直されます。何も壊れていないので、何度でも変更できます。

これがこのアドオンで言う「ノンデストラクティブ」で、Blender 標準のモデリング
機能ではなくこちらを使う一番の理由です。20 手前に作った直方体が、今も寸法を
編集できる直方体のままです。

形状を直接動かすこともできます。ビューポートでプロキシを選び、いつもどおり
<kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> を使ってください。形状がリアルタイムに
追従します。

## 6. 穴を開ける

1. **Cyl** を押して円柱を追加する
2. 直方体を貫通する位置に動かす
3. **Active Property Editor** で、その円柱のブーリアン演算を「引く」に設定する

Feature Tree は上から下へ順に評価されるので、円柱はそれより上にあるすべてから
引かれます。**順序に意味があります。**これはレイヤーの重ね順ではなく、履歴です。

## 7. 角を丸める

1. 選択モードに入る：**Selection Mode > ENTER Selection Mode**
2. 面を選ぶのか稜線を選ぶのかを、選択タイプのボタンで決める
3. ビューポートで対象の稜線をクリックする
4. **Modify & Pattern** を開いて **Fillet** を押す

> **ヒント：**選択モード中に <kbd>Alt</kbd> を押し続けると、モードを抜けずに
> 通常の Blender ギズモを使えます。

**Chamf**（面取り）も同じ手順で、丸めるかわりに平らに削ります。

## 8. 品質と速度を調整する

**Quality & Export** パネルは、カーネルの計算結果を表示用メッシュに変換する
細かさを決めます。

- **Linear** / **Curvature** — 表示用の分割の細かさ。値を小さくすると細かく、
  そのぶん重くなります
- **Fast Modifier Preview** / **Live Boolean Preview** — ドラッグ中の応答性と
  引き換えに、正確さを落とします。プレビューがおかしく見えるときは切って
  ください。**確定後の結果は常に正確に計算されます**
- **Use High Quality Bake** — ベイク時にだけ使われる、別系統の細かい設定。
  表示は粗いままで作業しつつ、出力だけ細かくできます

## 9. 履歴を巻き戻す

Feature Tree の各行の右端にピンのアイコンがあります。ある行にピンを刺すと、
そこまでで評価が止まり、それ以降はグレーアウトして無視されます。

途中の状態を確認したいときや、履歴の前のほうを編集するあいだ全体の反応を保ちたい
ときに使います。ピンを外すと全体の評価に戻ります。

なお、新しい操作は常にツリーの**末尾**に追加され、ピンの位置には入りません。
ピンを刺したまま形状を作ると、ピンより下に置かれて評価されないため、
何も起きなかったように見えます。

## 10. 結果を書き出す

目的が違う2つの方法があります。

**Bake to Mesh**（`Quality & Export > Bake to Mesh`）は、パーツを通常の Blender
メッシュに変換します。レンダリング、スカルプト、その他 Blender のジオメトリを
必要とする用途はこちらです。レンダリング用なら、先に **Use High Quality Bake**
を有効にしてください。

**Export STEP**（`Quality & Export > Export > STEP`）は、他の CAD ソフトで使える
本物の B-Rep の STEP ファイル（AP214 IS）を書き出します。三角形近似ではなく、
厳密な曲面がそのまま保存されます。

> **スケール：**書き出し時、**1 Blender 単位 = 1 mm** として出力されます。
> 10 単位の直方体は、FreeCAD や Fusion では 10 mm の直方体になります。寸法を
> 決めるときはこれを前提にしてください。
>
> 現在の STEP 書き出しには、パーツ名・色・アセンブリ構造は含まれません。
> 形状は正確ですが、それ以外の情報は入っていません。

## 次に読むもの

- **Import STEP** / **Import SVG** — 外部の形状を履歴に取り込む
- **Start Sketch** — 平面や既存の面の上に、拘束つきの2Dプロファイルを描く
- **Modify & Pattern** — Mirror（鏡像）、Array（配列）、Circ（円形配列）、
  Link（リンク複製）
- **Cleanup (Unify)** — 同一平面上の面を統合します。**意図的に手動操作**に
  してあり、自動では適用されません。面を統合すると、フィレットやオフセットが
  参照している面の識別情報が失われるためです

## うまくいかないとき

**Seamless タブに、ワークスペースのパネルより下が出てこない**
有効なパーツコレクションが選ばれていません。**Active CAD Workspace** の
ドロップダウンから選ぶか、**Add New CAD Part** を押してください。

**Hide Occluded Edges がグレーアウトして押せない**
これは仕様です。面が深度を書き込むのは「WGPU オーバーレイが OFF」かつ
「不透明」のときだけで、それ以外の条件ではこの設定は効きません。押せるのに
何も起きない状態を避けるため、あえて無効化しています。

**ドラッグ中は形状が変だが、離すと正しくなる**
高速プレビューによるものです。常に正確な結果を見たい場合は、**Fast Modifier
Preview** と **Live Boolean Preview** を切ってください。

**編集しても結果が更新されない**
**Modify & Pattern > Topology** の更新アイコンを押すと、強制的に再計算されます。
