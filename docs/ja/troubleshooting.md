# 困ったとき

## そもそも何も計算されない

`Edit > Preferences > Add-ons` を開き、Seamless CAD を展開してください。
**CAD Engine: Running / Not running** が表示されます。これは決め打ちの値ではなく、
**カーネルプロセスの実際の状態**を見ています。

Not running なら、カーネルプロセスの起動に失敗したか、終了しています。Blender を
再起動してください。繰り返し起きる場合は **Enable ERROR Logs**（既定で有効）を
確認したうえで、Blender のコンソール出力を見てください。

## Seamless タブに、ワークスペースのパネルより下が出てこない

有効なパーツコレクションが選ばれていません。**Active CAD Workspace** より下の
パネルは、有効なパーツがあるときにだけ表示されます。

ドロップダウンからパーツを選ぶか、**Add New CAD Part** を押してください。

## パネルが消えて「Sketch Mode」だけになった

スケッチモードに入っています。スケッチモード中は通常のパネルが隠れます。
スケッチパネル下部の **Apply** か **Cancel** で抜けてください。

## ドラッグ中は形状が変で、離すと正しくなる

高速プレビューが正常に働いている状態です。**Fast Modifier Preview** と
**Live Boolean Preview** はドラッグ中に近似を表示し、離した時点の結果は厳密に
計算されます。

常に厳密な形状を見たい場合は、**Quality & Export** で切ってください。
[品質とパフォーマンス](quality.md) を参照。

## Blender を2つ開いていて、片方でプレビューされない

現時点ではそういう仕様です。形状計算を行うカーネルはローカルの固定ポートを使い、
最初に起動した Blender がそれを掴みます。2つ目は自分専用のカーネルを起動せず、
その同じカーネルへ接続します。つまり、別のモデルを保持しているプロセスに向かって
自分の形状を描かせようとしている状態です。

参考用に開いているだけのファイルは Bake to Mesh するか、そちらでアドオンを無効に
するか、片方を閉じてからもう片方で作業してください。
[既知の制限](limitations.md) も参照してください。

## 編集しても何も更新されない

**Modify & Pattern > Topology** の更新アイコンを押すと、完全な再計算を強制できます。

これで毎回直るようなら、ログを取る価値があります。設定で **Enable WARN Logs** を
有効にして、出た内容を報告してください。

## Hide Occluded Edges がグレーアウトしている

不具合ではなく仕様です。面が深度を書き込むのは、**Use WGPU Overlay** が OFF かつ
**Opacity** が完全な不透明のときだけです。それ以外の組み合わせでは、この設定が
使う情報が存在しません。

WGPU オーバーレイを切り、不透明度を完全な不透明にすると使えるようになります。

## Edit Sketch がグレーアウトしている

パネルに「Hidden by rollback point」と出ているはずです。その項目は有効な
ロールバックピンより下にあり、現在は評価対象になっていません。

Feature Tree のピンのアイコンを押して解除してから編集してください。

## 前のほうを変更したらフィレットやオフセットが壊れた

Fillet、Chamfer、Offset、Shell、Draft は、カーネルのトポロジー上の特定の面・稜線の
**同一性**を参照しています。ほとんどの編集はこの同一性を保つので、寸法を変えても
操作は生き残ります。ただし保たない編集もあります。

**よくある原因は、ツリー上でその操作より上にある Cleanup (Unify) です。**同一平面上の
面を統合すると、統合された面の同一性が失われます。Cleanup が手動操作であり、
書き出し直前の最終工程にとどめるのが良いのはこのためです。
[仕組み](concepts.md) を参照してください。

該当する操作の対象を選び直せば復旧します。

## スケッチモードで Distance のボタンが消えた

このボタンは、現在の選択が距離拘束を取れる状態で、**かつまだ付いていない**ときに
だけ表示されます。見当たらないなら、その拘束はすでに存在しています。

**Selection Info** を見てください。既存の拘束の値をそこで編集できます。円弧の場合は
**Length** ではなく **Radius** として表示されます。

## スケッチが思ったように動かない

たいていは拘束の過剰です。スケッチパネルの **Constraints / Parameters** を有効に
すると、すべての拘束が対象 ID つきで一覧表示されるので、動きを止めている拘束を
見つけて削除してください。[スケッチ](sketching.md) を参照。

## 特定の操作ではなく、全体的に遅い

何をしても遅い場合（本来なら余裕があるはずのマシンでも）、上から順に確認してください。

1. **カーネルプロセスの居残りを確認する。** タスクマネージャ（Ctrl+Shift+Esc）→
   詳細タブ → `cad_server.exe` を探します。複数ある場合、あるいは異常終了した
   セッションのものが残っている場合は、すべて終了してから Blender を起動し直して
   ください。古いカーネルは間違った状態を保持したまま応答を続けます。
2. **Use WGPU Overlay を OFF にし、Opacity を完全不透明にする。** この2つは互いに
   影響するため、片方ずつ試すと効果を見落とします。Overlay は実験的機能で、
   OFF のほうが速く動く想定です。
3. **セキュリティソフトがローカル通信を検査していないか確認する。** Blender と
   カーネルはローカルの TCP ポートで通信します。この通信にフックするソフトが
   入っていると、すべての操作が体感できるほど遅くなります。
4. **プロファイルを取る。** 設定で **Perf Logging** を有効にし、遅い操作を1回
   行ってから、OS の一時ディレクトリにある `seamless_cad_profile.log` を確認します。
   時間がどこで消えているかが分かるので、推測より確実です。

報告する際は、**ドラッグ中・離した瞬間・起動時**のどれが遅いのかを書いてください。
それぞれ処理のどの層かが違うので、原因の絞り込みが大きく進みます。

## 前のほうの操作を編集すると重い

想定どおりの挙動です。編集した操作より後ろをすべて計算し直す必要があるため、長い
履歴の上のほうを編集するのは、下のほうより高くつきます。これは履歴ベースの CAD の
本質的な性質です。

作業中の操作のすぐ下にロールバックポイントを置いてください。ピンより下は、解除
するまで評価されなくなります。

## 他の CAD で寸法が1000倍ずれる

STEP 書き出しでは **1 Blender 単位が 1 mm** として書かれます。10 単位の直方体は
10 mm になります。1単位＝1mと想定してシーンを作っていた場合、すべてが1000分の1の
大きさになります。

書き出し側にスケールのオプションはないので、対処は「正しいスケールで作る」か
「受け取り側でスケールし直す」かのどちらかです。

## 書き出した STEP に色が入っていない

そのとおりで、想定された挙動です。アドオン側に色を設定する場所が無いため、
ファイルに運ぶ元の色が存在しません。

**名前とアセンブリ構造は入ります。**もし名前が入っていないなら、書き出したのが
STEP ではなく IGES でないか確認してください。IGES は形状のみです。製品名は Part の
コレクション名から取るので、コレクション名を変えればファイル内の名前も変わります。
[読み込みと書き出し](import-export.md) を参照してください。

## 不具合を報告するとき

添えていただけると助かる情報です。

- Blender のバージョンと、**レガシーアドオンとして入れたか、Blender 4.2+ の
  Extension として入れたか**
- 設定画面の **CAD Engine** の表示
- **Enable WARN Logs** を有効にした状態のコンソール出力
- パフォーマンスの問題なら、**Perf Logging** を有効にして、OS のテンポラリ
  ディレクトリの `seamless_cad_profile.log` を添付
