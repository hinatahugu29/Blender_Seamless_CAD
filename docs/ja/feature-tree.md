# Feature Tree と Part

> 2026-08-10 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/feature-tree/) を参照してください。
>
> **アドオンの UI は英語です。** このページではボタン名を英語のまま書きます。

Feature Tree がモデルそのものです。ビューポートに出ているのは、それを今の時点で
評価した結果にすぎません。実際に編集しているのはツリーのほうです。

このページは **Feature Tree** パネルと、その上の **Active CAD Workspace** パネルの
リファレンスです。なぜこういう仕組みなのかは [仕組み](concepts.md) を参照して
ください。

## 1行の見かた

各行が1つの操作で、左から順に次のコントロールが並びます。

| コントロール | 動作 |
|---|---|
| ラジオボタン | その項目を**アクティブ**にします。下の **Active Property Editor** にパラメータが出ます |
| チェックボックス | **Group Selection** の対象として印を付けます。それ以外の用途はありません |
| 名前とアイコン | ここを押してもアクティブになります。アイコンは操作の種類を表します |
| 複製 | 項目をコピーし、コピーをアクティブにします |
| **X** | 項目を削除します |
| ピン | **ロールバックポイント**の設定・解除 |

ロールバックポイントより下の行はグレーアウトし、ボタンも無効になります。

グループの中の項目はインデントされるので、入れ子が一目で分かります。

### 曲線の項目はその場で展開される

**Curv** / **Plin** / **Surf** の項目がアクティブなとき、ツリーはその下に展開し、
各制御点を `P0`, `P1`, … として編集可能な座標で並べます。点ごとに追加・削除の
ボタンが付き、末尾には **Add Point** が出ます。Polyline の場合は、さらに角ごとの
フィレット切り替えが付きます。

制御点を数値で編集できるのはここだけです。

## 順序は作成順で、固定される

ツリーは**上から下へ**評価され、位置は**作成した順**で決まります。

ここから2つのことが言えます。長いモデルを組む前に知っておく価値があります。

- **行の並べ替えはできません。**上へ・下へ移動する機能はありません。
- **新しい操作は常に末尾に追加されます。**途中に挿し込む方法はありません。
  ロールバックポイントを刺してもこれは変わらず、ピンを刺したまま作った項目も
  最下部、つまり**ピンより下**に置かれます。そこはグレーアウトされ評価されない
  ため、作ったはずの形状が出てこないときは、まずピンの有無を確認してください。

そのため、順序は組み立てながら考えることになります。すでに作ったものより前に
操作を入れたい場合、現実的な選択肢は、後ろの項目を消して作り直すか、既存の項目の
働きを変えるかです。

- 項目の **Operation** を変える — 同じ形状を結合ではなく切り取りに変えるだけで、
  並べ替えたかったことの多くは済みます
- **グループ**を使い、一連の項目を1つのまとまりとして合成する
- `Base` と **Separate Previous to New Part** で2つの Part に分ける

例外は **Edit Sketch** です。スケッチを編集し直すと、その項目は元の位置のまま
作り直されるので、下流のフィレットなどは付いたままになります。ただしこれは、
スケッチが作る閉領域の数が変わらない場合に限ります。数が変わると作り直された項目は
末尾に移り、下流の割り当てをやり直す必要があるかもしれない旨の警告が出ます。

## Operation（合成方法）

すべての項目は、それより上の累積結果に対して、**Operation** に従って合成されます。
設定は Property Editor にあります。

| 値 | 効果 |
|---|---|
| `Base` | それより上をすべて破棄し、ここから始め直す |
| `Add (Fuse)` | 結合。既定値 |
| `Subtract (Cut)` | ここまでの結果から切り取る |
| `Intersect (Common)` | 重なった部分だけを残す |

### Base と Part の分割

`Base` にした項目は履歴を2つに切ります。それより上は結果に寄与しなくなります。
このとき Property Editor に **Separate Previous to New Part** が出ます。破棄された
上側を、無効なまま放置するかわりに独立した Part にする機能です。

2つのうちどちらかを選ばされます。

| モード | 効果 | リスク |
|---|---|---|
| **Move (Clean up original)** | 前半の項目をこの Part から移動します | 下流がそれらを参照していた場合（フィレットの対象面、パターンのターゲットなど）、参照が切れます |
| **Copy (Keep references)** | 新しい Part にコピーし、こちらにも履歴として残します | 参照は安全。ただし元のスタックは短くなりません |

移動する項目に依存しているものが下流に無いと確認できていない限り、**Copy** を
選んでください。

## ロールバック

ピンはロールバックポイントを設定します。評価はそこで止まり、それより下は無視され
グレーアウトします。すでにピンが刺さっている行のピンをもう一度押すと解除されます。

用途は3つあります。

- 途中の状態を**確認する**
- **Edit Sketch** など、下流を巻き込みたくない編集を安全に行う
- **パフォーマンス。**ピンより下は評価されなくなります。長い履歴の前のほうを
  編集するあいだ反応を保つ手段としては、これが単独で最も効きます

ロールバックで対象が隠れているあいだ、意図的に無効になるコントロールがあります。
実際に出会うのは **Edit Sketch** です。黙って何も起きないのではなく
「Hidden by rollback point」と表示されます。

## グループ

**Group (** と **Group )** は、対になるマーカーを挿入します。その間にある項目は、
1つずつ順にではなく、**1つのまとまりとして**残りのモデルと合成されます。

パネル上部の **Group Selection** は、チェックを入れた行を新しいグループで囲みます。
これには規則があり、破ると理由を表示して中止します。

- **2行以上**で、かつ**連続した範囲**であること。間が飛んでいる選択は拒否されます
- **既存のグループの境界をまたげません。**新しいグループは、古いグループの内側か
  外側にきれいに入れ子にならなければならず、境界をまたぐ形にはできません
- 新しいグループの中の行が**外側の項目を参照している**場合（スイープのパス、
  ロフトのプロファイル、パターンのターゲットなど）、参照がグループ境界をまたぐ
  ことになるため警告が出ます

## ターゲット — 他の項目を指す項目

すべての項目が自前の形状を持っているわけではありません。Mirror / Array / Circ /
Link / Sweep / Loft は、**他の項目**に対して働き、その相手を位置ではなく内部の
UUID で参照します。指定する方法は2つあります。

- **Pick Target（リスト）** — この Part の他の項目を名前で並べたダイアログ
- **Pick Target in Viewport** — ビューポートで対象をクリックして指定

参照が UUID なので、ツリーの上のほうを編集しても壊れません。ただし、ターゲットを
**削除**した場合と、**Separate Previous to New Part** の Move で別 Part に移した
場合は切れます。

モディファイア系（Fillet / Chamfer / Offset / Inset / Draft / Shell）は仕組みが
違います。項目全体ではなく、[Selection Mode](shortcuts.md) で選んだ個別の面や
稜線を参照します。

## Part

サイドバー最上部の **Active CAD Workspace** パネルで、編集中の Part を切り替えます。

| コントロール | 動作 |
|---|---|
| ドロップダウン | アクティブな Part を選ぶ |
| **Add New CAD Part** | 独立した Part をもう1つ作る |
| ゴミ箱アイコン | アクティブな Part を削除し、そのジオメトリを解放する |

これより下のパネルはすべて**アクティブな Part にだけ**効きます。下のパネルが
そもそも出ていない場合は、有効な Part が選ばれていません。ドロップダウンから
選んでください。

Blender のアウトライナ上では、Part はコレクションです。`Seamless_CAD` コレクションの
中に `Part_1`, `Part_2`, … が並び、ベイク結果を受け取る `Result` コレクションが
別にあります。名前は空いている番号から埋まるので、`Part_2` を削除してから新しい
Part を作ると `Part_3` ではなく `Part_2` になります。

**評価されるのはアクティブな Part だけです。**そのためモデルを複数の Part に
分けることは、整理の手段であると同時にパフォーマンスの手段でもあります。
[品質とパフォーマンス](quality.md) を参照してください。
