# モデリング操作

**Create** パネルと **Modify & Pattern** パネルのリファレンスです。背景にある
考え方は [仕組み](concepts.md) を参照してください。

以下のすべての操作は Feature Tree に項目を追加し、追加した項目は後からいつでも
選び直して編集できます。

---

## Create（作成）

### ソリッド

| ボタン | 形状 |
|---|---|
| **Box** | 直方体 |
| **Cyl** | 円柱 |
| **Sph** | 球 |
| **Cone** | 円錐（第2半径を与えると円錐台） |
| **Torus** | トーラス |

### 曲線・プロファイル

| ボタン | 形状 |
|---|---|
| **Curv** | ベジェ曲線 |
| **Plin** | ポリライン。角ごとにフィレットの有無を指定できます |
| **Arc** | 円弧 |
| **Surf** | サーフェス |
| **Slot** | 長穴 |
| **Poly** | 正多角形 |
| **Gear** | パラメトリックな歯車 |
| **Helix** | らせん |
| **Rev** | 回転体。プロファイルを軸まわりに回転させます |

**Curv** / **Plin** / **Surf** の項目がアクティブなときは、Feature Tree がその場で
展開し、各制御点が `P0`, `P1`, … として編集可能な座標で表示されます。点の挿入・
削除ボタンも並びます。**Plin** の場合は各点にフィレットの切り替えも付きます。

### スイープ形状

| ボタン | 形状 |
|---|---|
| **Sweep** | プロファイルをパスに沿って掃引 |
| **Loft** | 2つ以上のプロファイル間をブレンド |

### グループ化

**Group (** と **Group )** は、対になるマーカーを Feature Tree に挿入します。その
間にある項目は一つのまとまりとして扱われ、ツリー上ではインデントされて入れ子が
見えるようになります。一連の操作を、1個ずつではなくまとめて残りのモデルと合成
したいときに使います。

Feature Tree パネル上部の **Group Selection** は、チェックを入れた行を新しい
グループで囲みます。

### スケッチ

| ボタン | 動作 |
|---|---|
| **Start Sketch** | 平面上でスケッチモードに入る |
| **on Face** | 先に既存の面を選び、その上でスケッチする |

[スケッチ](sketching.md) を参照してください。

**Dynamic Box Loft Hole**（`Dynamic Box Hole`）は、ロフトで駆動される箱状の穴を
作ります。単純なブーリアンでは足りない場合に使います。

## Modify & Pattern（修正とパターン）

### Modification（修正）

これらは **Selection Mode** で選んだ面や稜線に対して働き、パラメータは
**Active Property Editor** に表示されます。

| ボタン | パラメータ | 備考 |
|---|---|---|
| **Fillet** | Fillet Radius | 選んだ稜線を丸めます。稜線ごとに別半径を指定可能（後述） |
| **Chamf** | Chamfer Distance | 丸めるかわりに平らに削ります |
| **Offset** | Offset Distance | 選んだ面を法線方向に移動します |
| **Inset** | Inset Distance / Depth (Push/Pull) | 面を内側に取り、必要なら押し引きします |
| **Draft** | Draft Angle | 面に抜き勾配をつけます。**Neutral Plane** と **Faces to Taper** の両方が必要です |
| **Shell** | Thickness | 中空化します。**Faces to Remove** で選んだ面が開口部になります |
| **Face Loft** | — | 選んだ面の間をロフトします |
| **Face Rev** | — | 選んだ面を回転させます |

**可変フィレット。**Fillet に対象が設定されると、Property Editor が稜線を1本ずつ
列挙し、**Use Default** / **Custom** の切り替えを表示します。Custom にした稜線だけが
独自の半径を持ち、残りはメインの値に従います。

**スポイトのアイコン**が Offset と Inset の横にあります。これを押すとインタラクティブな
ピックが始まり、数値を打つかわりにビューポートでドラッグして距離を決められます。

**Draft** は2種類の選択を必要とし、両方そろうまで「Select base face and draft face」と
表示し続けます。Neutral Plane が動かない基準面、Faces to Taper が傾く面です。

### Topology（トポロジー）

**Cleanup (Unify)** は同一平面上の面を統合し、トポロジーを単純化します。

**これは意図的に手動操作です。**面を統合すると、Fillet・Offset・Shell が参照して
いる面の同一性が失われるため、生きた履歴の途中で適用すると、それより下の操作を
壊すことがあります。書き出し直前の最終工程として使うのが最も安全です。理由は
[仕組み](concepts.md) を参照してください。

隣の**更新アイコン**は完全な再計算を強制します。編集後に結果が古いまま見えるときに
使ってください。

### Layout & Patterns（配置とパターン）

| ボタン | 操作 |
|---|---|
| **Mirror** | 積み上げた結果を鏡像化 |
| **Array** | 線形配列 |
| **Circ** | 円形配列 |
| **Link** | リンクされたインスタンス |

この4つには Property Editor に **Independent** の切り替えがあります。パターン自身の
トランスフォームを、元の形状のトランスフォームの上に重ねるか、独立させるかを
決めます。

## Placement & Snap（配置とスナップ）

| コントロール | 動作 |
|---|---|
| **Surface Snapping** | 新しく置く形状を既存の面にスナップさせます |
| **Interactive Placement** | ビューポートをクリックして形状を配置します |
| **Visual Snap Move** | 既存の形状をスナップ補助つきで移動します |

新しく作られた形状は 3D カーソルの位置に出ます。どの規則が適用されたかは
ステータスメッセージが伝えます。「Placed at Cursor (Snapping is OFF)」という表示も
あるので、**スナップに失敗したのか、そもそも切れていたのか**を区別できます。

---

## トランスフォーム

ほとんどの項目で、Property Editor は2種類のトランスフォームを別々に表示します。

- **Global** — シーン内での位置
- **Local Offset** — 形状自身の座標系で加える追加のオフセット

分けてあるおかげで、継承した配置を崩さずに、形状自身の向きを基準にした微調整が
できます。
