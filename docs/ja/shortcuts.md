# キーボードとマウス

> 2026-08-10 時点の英語版に対応。最新の情報は [English documentation](https://hinatahugu29.github.io/Blender_Seamless_CAD/shortcuts/) を参照してください。
>
> **アドオンの UI は英語です。** このページではボタン名を英語のまま書きます。

Seamless CAD は**グローバルなショートカットを一切追加しません。**キーマップに項目を
登録していないので、いま使っている Blender の操作は何も変わりません。

このページのキーはすべて、アドオンのインタラクティブなモードが動いているあいだ
だけ効きます。モードの外では Blender はいつもどおりです。<kbd>G</kbd> /
<kbd>R</kbd> / <kbd>S</kbd> で CAD 形状が動くのもそのためで、動かしているのは
通常の Blender オブジェクト（プロキシ）であり、ジオメトリがそれに追従しています。

ビューポートの操作（中ボタン、ホイール、テンキーの視点）は、以下のどのモードでも
そのまま通ります。回り込むためにモードを抜ける必要はありません。

**業界標準キーマップ（Industry Compatible）にも対応しています。** モードの中でも
<kbd>Alt</kbd> ＋マウスボタンで回転・パン・ズームができます。ひとつだけ、選択モードは
このキーがアドオン側とぶつかります（<kbd>Alt</kbd> ＋左ドラッグがギズモの軸移動）。
カーソルの下にあるもので判断します。ギズモの軸か制御点の上なら掴み、それ以外なら回ります。

> **8.1.5.8** より前は、スケッチモード・選択モードでテンキーの視点切り替えが効かず、
> 業界標準キーマップにも対応していませんでした。

## スケッチモード

**Start Sketch** または **on Face** から、**Apply** / **Cancel** を押すまでの間。

### 描画と編集

| 操作 | 動作 |
|---|---|
| 左クリック | 点を置く / 現在のツールの次の手順を確定する |
| ジオメトリ上で左ドラッグ | 点・線・選択範囲全体を移動。移動中も拘束は満たされたままです |
| 何もない場所で左ドラッグ | ボックス選択。**Select ツールのみ** |
| <kbd>Shift</kbd>+何もない場所でドラッグ | ボックス選択（追加） |
| <kbd>Shift</kbd> 押しっぱなし | 軸ロック。ドラッグ開始点から見て水平か垂直に拘束します |
| 右クリック / <kbd>Esc</kbd> | 現在のペンツールを抜けて **Select** に戻る |
| <kbd>Del</kbd> または <kbd>X</kbd> | 選択を削除 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 元に戻す。スケッチモードは Blender とは**別のアンドゥ履歴**を持ちます |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | 選択のコピー / 貼り付け |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | すべて選択 |
| <kbd>L</kbd> | チェーン選択（つながっている一連のジオメトリ）。**Select ツールのみ** |
| <kbd>Alt</kbd>+ホイール | グリッドの刻みを半分 / 倍にする |
| 寸法ラベルを左クリック | その寸法の値を編集。**Select ツールのみ** |

> **右クリックと <kbd>Esc</kbd> は消費されます。**スケッチ中は Blender の
> コンテキストメニューも開かず、モーダルのキャンセルも起きません。これは意図的な
> 設計です。誤った右クリックで未適用のスケッチを失う代償が大きすぎるためです。

> **<kbd>Enter</kbd> と <kbd>Space</kbd> ではスケッチを確定できません。**
> スケッチを終える手段は、サイドバーの **Apply** と **Cancel** のボタンだけです。
> これも意図的です。

### 描画中のスナップ

スナップは自動です。何に吸着したかはインジケータが示します。

| 表示 | 意味 |
|---|---|
| 点のハイライト | 既存の点にスナップ |
| 緑の三角（△） | 線分の中点にスナップ |
| 白い点線のガイド | インファレンス。既存の点と X または Y が揃っている |

**Grid Snap** は押しっぱなしのキーではなくサイドバーのトグルです。<kbd>Shift</kbd>
の軸ロック中は一時停止します。両方効くと同じ座標を取り合うためです。

**Vertex Snap** は、点が繋がる2つの経路の両方を制御します。

- 近くに既存の点があるとき、新しい点を作らずにその点を使い回す
- **ドラッグした点を他の点の近くで離すと、2つがマージされる**（ドラッグした側が
  削除され、それを参照していたものが差し替わります）

既定は ON で、サイドバーにトグルがあります。たまたま近くに来ただけで繋げたくない
ときは、<kbd>Ctrl</kbd> を押しながらクリック・ドラッグするとそのあいだだけ無効になります。

マージされる距離は、カーソルを近づけて点が光る距離と一致します。つまり
「光ったらマージされる」と考えてください。**8.1.5.8** より前は、これがシーン単位の
固定距離で、ズームしても変わらないためグリッド1マス隣の点まで吸い込むことがありました。

OFF にしても頂点の選択はできます。選択モードのクリック判定は吸着とは別のもので、
どちらの設定でも効きます。

## Selection Mode（選択モード）

**Selection Mode > ENTER Selection Mode** から入ります。Fillet / Chamfer /
Offset / Inset / Draft / Shell が対象とする面と稜線を選ぶためのモードです。

| 操作 | 動作 |
|---|---|
| 左クリック | ハイライトされた面・稜線を選ぶ（**置き換え**）。すでに選ばれている要素をクリックすると外れます |
| <kbd>Shift</kbd>+クリック | 置き換えず追加する |
| <kbd>Ctrl</kbd>+クリック | **稜線のみ。**最後に選んだ稜線からここまでの最短経路を一括選択。<kbd>Ctrl</kbd> を押しながらホバーすると、確定前に経路がプレビュー表示されます |
| <kbd>Alt</kbd> 押しっぱなし | 選択モードを抜けずにトランスフォームのギズモを表示・使用 |
| <kbd>Shift</kbd>+<kbd>D</kbd> | アクティブな Feature Tree 項目を複製 |
| 右クリック / <kbd>Esc</kbd> | 選択モードを抜ける |

覚える価値が高いのは <kbd>Ctrl</kbd>+クリックです。ポケットの周囲の稜線を1本ずつ
拾うのは時間がかかりますし、経路のプレビューがあるので何が選ばれるか先に分かります。

### 曲線の制御点をドラッグ中

**Curv** / **Plin** / **Surf** の制御点をドラッグしているあいだ:

| キー | 動作 |
|---|---|
| <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | その軸に拘束。もう一度押すと解除 |
| <kbd>Shift</kbd>+<kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | 軸ではなくその**平面**に拘束 |
| <kbd>S</kbd> | スナップの ON / OFF |
| <kbd>V</kbd> | 頂点スナップ |
| <kbd>M</kbd> | 中点スナップ |
| <kbd>F</kbd> | 面スナップ |
| <kbd>C</kbd> | スナップ OFF |

## Interactive Placement / Interactive Transform

**Placement & Snap** から起動します。ステータスバーにもキーが表示されます。

| キー | 動作 |
|---|---|
| <kbd>S</kbd> | スナップの ON / OFF |
| <kbd>N</kbd> | **Align to Normal** の切り替え。着地する面の向きに合わせます |
| <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | 移動をその軸に拘束 |
| <kbd>Ctrl</kbd> 押しっぱなし | その瞬間だけ頂点スナップ |
| <kbd>Shift</kbd> 押しっぱなし | その瞬間だけ中点スナップ |
| 左クリック | 確定 |
| 右クリック / <kbd>Esc</kbd> | 中止 |

---

## Visual Snap Move

**Placement & Snap > Visual Snap Move** から起動します。動かす側の点を選び、
次に着地させたい点を選びます。

| 操作 | 動作 |
|---|---|
| 何も押さない | **面**にスナップ |
| <kbd>Shift</kbd> 押しっぱなし | **稜線**にスナップ |
| <kbd>Ctrl</kbd> 押しっぱなし | **頂点**にスナップ |
| <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | その軸に拘束（着地点を選ぶ段階のみ） |
| <kbd>Shift</kbd>+<kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | その平面に拘束 |
| 左クリック | 現在の点を確定 |
| 右クリック / <kbd>Esc</kbd> | 中止 |

同じ「押しっぱなしで切り替える」方式は、Offset と Inset の横にある**スポイト**にも
使えます。数値を打つかわりに、ジオメトリから距離を拾うためのものです。
