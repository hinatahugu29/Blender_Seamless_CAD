# Seamless CAD

Неразрушающее CAD-моделирование внутри Blender.

Формы вычисляет **OpenCASCADE (OCCT)**, а не система полигональных сеток
Blender; результат отрисовывается в окне вида. Примитивы, булевы операции,
скругления и фаски хранятся в виде **Feature Tree** — истории построения,
к которой можно вернуться и отредактировать её в любой момент. Двигайте прокси
клавишами <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> — геометрия следует за ними
в реальном времени.

Результат выводится двумя способами: **Bake to Mesh** для работы внутри Blender
или **Export STEP** — настоящий B-Rep-файл, который откроют другие CAD-системы.

> **Бета-версия.** Только Windows. Тестовые сборки для macOS и Linux существуют,
> но не являются готовым продуктом.
