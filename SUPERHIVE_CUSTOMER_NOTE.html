🚀 Quick Installation Guide

  1. Download the Addon ZIP: Download CAD_8_1_5_1.zip (or the latest version provided below). Do NOT unzip the file!
  2. Open Blender: Launch Blender (Version 4.2 LTS to 5.1+ supported).
  3. Install Addon:
    • Go to Edit > Preferences > Add-ons
    • Click Install... (or Extension Manager > Install from Disk in Blender 4.2+)
    • Select the downloaded ZIP file and click Install Add-on.
  4. Enable Addon: Check the box next to "Blender CAD" to activate it.
⚠️ System Requirement Reminder:
This addon is currently built for Windows 10/11 (64-bit). If you encounter any DLL or bridge initialization errors, please ensure you have installed the Microsoft Visual C++ Redistributable.
