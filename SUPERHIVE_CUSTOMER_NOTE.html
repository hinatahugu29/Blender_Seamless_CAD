🚀 Quick Installation Guide

  1. Download the add-on ZIP from your Superhive library. Do not unzip it — Blender wants the ZIP itself.
  2. Open Blender (4.2 LTS through 5.1).
  3. Install:
    • Go to Edit > Preferences > Add-ons
    • Click Install... (in Blender 4.2+ this may appear as Install from Disk in the dropdown menu)
    • Select the downloaded ZIP file
  4. Enable it: Tick the checkbox next to "Seamless CAD".
  5. Find it: In the 3D viewport, press N to open the sidebar and choose the Seamless tab.

The first launch starts a background geometry server. If Windows Defender or your firewall asks about it, that is the CAD kernel talking to Blender on your own machine — nothing leaves your computer.

⚠️ A word about the Beta:
This is an active work in progress. Please save often, and keep a backup of important files. If something behaves strangely, it is worth reporting — that is how it gets fixed.

System requirement: Windows 10 / 11 (64-bit). Everything the add-on needs is bundled, so there is no separate runtime to install.
