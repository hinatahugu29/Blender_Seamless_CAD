🚀 Quick Installation Guide

  1. Download the add-on ZIP from your Superhive library. Do not unzip it — Blender wants the ZIP itself.
  2. Open Blender (4.2 LTS through 5.1).
  3. Install:
    • Go to Edit > Preferences > Add-ons
    • Click Install... (in Blender 4.2+ this may appear as Install from Disk in the dropdown menu)
    • Select the downloaded ZIP file
  4. Enable it: Tick the checkbox next to "Seamless CAD".
  5. Find it: In the 3D viewport, press N to open the sidebar and choose the Seamless tab.

The first launch starts a background geometry server. If Windows Defender, or a firewall prompt on any platform, asks about it, that is the CAD kernel talking to Blender on your own machine — nothing leaves your computer.

On macOS: the kernel is ad-hoc signed but not notarised by Apple. It usually runs anyway, because Blender unpacks the zip itself. If the add-on loads but no geometry ever appears, run this in Terminal and restart Blender — then please tell me you had to, because that is something I cannot find out from here:

xattr -dr com.apple.quarantine ~/Library/Application\ Support/Blender/*/scripts/addons/CAD_8_1_5_1

⚠️ A word about the Beta:
This is an active work in progress. Please save often, and keep a backup of important files. If something behaves strangely, it is worth reporting — that is how it gets fixed.

System requirements: Windows 10 / 11 (64-bit), Linux x86-64 (glibc 2.34+, so Ubuntu 22.04 / Debian 12 / RHEL 9 or later), or macOS on Apple Silicon. Intel Macs are not supported. Everything the add-on needs is bundled, so there is no separate runtime to install.

If you are on Linux or macOS, please read this bit. Those builds come from the same source and the same automated pipeline as the Windows one, and the pipeline checks that each compiles, bundles its libraries, starts and answers. Since 8.1.5.12 the Linux package is also put through the full test suite — 52 checks — exactly as you receive it. macOS has had none of that: no feature has been verified inside Blender on a Mac by me. Neither platform has had the checks that need a real screen, which are done on Windows only. If something does not work, it is worth reporting — on macOS especially, your report is the only thing there is.
