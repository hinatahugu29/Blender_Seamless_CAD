### 序（`PROLOGUE_dream_of_cad.md`）の扱い

連載の一部として出さず、**単独の読み物として1週間先行公開**する。理由：

- タイトルが連載中で最も拡散しやすい資産。最後に置くと、すでに買った人にしか届かない
- 論考であって体験談ではないので、記事0（個人的な痛みの話）と役割が重ならない。同じ「売らない回」でも語り口が違う
- CTA ブロックを**付けない**。末尾の1段落だけが導線。連載色を消しておくと、CAD 界隈・Blender 界隈の両方から引用されやすい
- 連載開始後に、末尾へ記事0へのリンクを追記する

ジオメトリノードへの反論を正面から扱っている節がある。ここを削ると論考として信用されなくなるので残すこと。

## 公開前にやること

## 文中で守っている方針

- **STEP を先頭に出さない。** Superhive の CAD 製品5つのうち4つが STEP インポーターなので、輸入ツールと誤解されると死ぬ。出口の話は最終回まで引っ張る
- **「3mm」を全記事で反復する。** 記憶に残る単位をひとつだけ作る
- **各記事に「できないこと」の節を必ず置く。** 個人開発で信用が売り物なので、制限を先に言うほうが売れる
- **note のエディタは Markdown の表とコードブロックを正しく扱わないため、本文では使っていない**（この README は除く）
- 数値・仕様は `INVENTORY_V8_1_5_1.md` と実測記録に基づく。バージョンが上がったら拘束数（14）・フィーチャー型（34）・OCCT（8.0.1）・ZIP サイズ（約41MB）を確認し直すこと
