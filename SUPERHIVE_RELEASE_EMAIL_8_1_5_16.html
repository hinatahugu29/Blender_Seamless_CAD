Seamless CAD

Version 8.1.5.16 is out

One number can now drive the whole part — plus the ability to switch a single feature off, and two fixes to how the add-on behaves when the geometry kernel gets something wrong.

Parameters: one value, everywhere it matters

A new Parameters panel holds named values — width = 40, hole = width / 4. Any feature's size, position, rotation, radius or count can be driven by an expression. Change width and everything that depends on it follows.

Rename a parameter and the expressions using it are updated for you. A typo or a circular reference is shown on its own row, and the model keeps its last good value instead of breaking. Expressions accept arithmetic and a short list of maths functions and nothing else — so a .blend file someone sends you cannot run code through them.

Switch one feature off

An eye icon on each Feature Tree row takes that feature out of the model without deleting it. Unlike the rollback pin, everything below it keeps working. Feature names are editable now too, and the object in the outliner follows the name you give it.

A fillet that cannot be built no longer wrecks the shape

The geometry kernel can report success and hand back a fillet that runs off into space — a spike where a rounded edge should be. It happens where the chosen edge ends tangent to another surface, such as an edge that stops exactly on the wall of a hole. A fillet or chamfer whose result is not plausible is now discarded and your previous shape is kept. If a fillet seems to do nothing on an edge like that, it was refused rather than ignored — and a smaller radius usually will not help, because the problem is the edge rather than the size.

The add-on checks which kernel it is talking to

Geometry is computed by a separate program that ships inside the add-on. On Linux that program cannot be overwritten while it is running, so it was possible to install an update, see the new version number, and still be running the old geometry code with nothing anywhere to tell you.

The add-on now asks the kernel which build it is, and says so in the console if it does not match.
Updating
Download the build for your platform from your Superhive library and install it through Blender's Install from Disk, the same way as before.

Quit every Blender window first. On Linux and macOS especially, installing while Blender is open can leave the old geometry program in place — the add-on will now warn you in the console if that happens, but starting clean avoids it entirely.
Two things that are still true

A large Inset on a face that already has a fillet can still come out wrong. This is a defect rather than a design limit. It is written up on the manual's Limitations page, and a report with the model is genuinely welcome.

macOS remains the least proven platform. The build is produced by the same automated pipeline as the others and is checked to compile, bundle, start, answer and package completely — but no individual feature has been confirmed inside Blender on a Mac by the developer. If you are on a Mac, your report is the only way that changes.
